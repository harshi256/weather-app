# 🌤 Python Weather App

A GUI-based weather application built using **Python** and **Tkinter** that fetches real-time weather data using the **OpenWeatherMap API**.

---

## 🔧 Features
- Search weather by city name
- Displays temperature, humidity, and weather condition
- User-friendly GUI using Tkinter
- Real-time API data
- Error handling for invalid cities

---

## 🛠 Technologies Used
- Python
- Tkinter
- Requests library
- OpenWeatherMap API
